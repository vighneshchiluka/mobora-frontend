# ✳ MOBORA – Mobile Accessories & Custom Covers

**Your design. Your style. Your MOBORA.**

MOBORA is a modern e-commerce platform for mobile accessories and personalized phone covers. It offers a clean shopping experience where customers can explore everyday mobile essentials, discover custom phone covers, and find products that match their style.

🌐 **Live Website:** [https://mobora-mobile-accessories.vercel.app/accessories](https://mobora-mobile-accessories.vercel.app/accessories)

---

## ✨ Features

- **Mobile Accessories Store** – Browse phone grips, USB-C cables, chargers, and screen protectors.
- **Custom Phone Covers** – Explore personalized phone cover options.
- **Product Filtering** – Filter accessories by category, price, and compatibility.
- **Product Search & Sorting** – Find products and organize product listings.
- **Wishlist** – Save products for later.
- **User Authentication** – Sign-in and registration experience.
- **Order Management** – Access order tracking and order-related information.
- **Responsive Design** – Optimized shopping experience across desktop and mobile devices.
- **Payment Integration** – Razorpay integration.
- **Cloud Deployment** – Deployed using Vercel and Cloudflare services.

## 🚀 Getting Started

Follow these steps to run MOBORA locally.

### 1. Clone the repository

```bash
git clone https://github.com/vighneshchiluka/moboro-store.git
```

### 2. Navigate to the project directory

```bash
cd moboro-store
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root and configure the environment variables required by the application.

Do not commit API keys, database credentials, payment secrets, or other sensitive information.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
